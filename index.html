Import workplaces from SCB

Load the file written by the SCB script (arbetsstallen_0580.csv and so on), or a point layer exported from QGIS as CSV or GeoJSON. Each workplace becomes its own point, and its likely outputs and inputs are filled in from its SNI codes using the SNI waste lookup table.

Recognised columns: namn/name, sni, sni_alla, kommun_namn, anstkl_text, gatuadress, cfar, enskild_firma, and coordinates as north/east (SWEREF 99 TM is detected and converted) or lat/lon. Rows without coordinates are skipped, and a workplace already loaded (same CFAR number) is not added twice. Import one municipality at a time.
